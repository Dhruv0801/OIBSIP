# To-Do Web App

Flowlist is a calm, minimal to-do app designed to help you plan your day without feeling overwhelmed. It organizes tasks into a "To-Do Garden" where items move from pending to done, and it tracks a daily focus streak along with mood tags like Flow, Deep Work, and Slow Day. Users can add tasks with optional deadlines and reminders, and the dashboard separates open loops (pending tasks) from wins (completed tasks) for a clear view of daily progress.
